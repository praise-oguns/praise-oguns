## Featured Projects

### 1. [Glasgow Air Quality Monitor](https://github.com/praise-oguns/glasgow-air-pollution-tracking)
**Python · AWS Lambda · EventBridge · DynamoDB · API Gateway · S3 · CloudFront · SNS**

A live dashboard that turns public air-quality readings into plain-English classifications and health guidance.

- Built a scheduled serverless data pipeline that refreshes readings every three hours.
- Processes pollutant readings and stores results in DynamoDB.
- Serves the dashboard through S3 and CloudFront with HTTPS.
- Uses SNS for email alerts when air quality reaches poor levels.

**[View live dashboard →](https://www.glasgowairquality.co.uk)**

### 2. [AWS CI/CD Pipeline with Jenkins and Terraform](https://github.com/praise-oguns/flask-cicd-aws-pipeline)
**AWS · Terraform · Jenkins · Docker · Nginx · Flask · Linux**

An automated deployment workflow for a Flask currency converter, with infrastructure defined as code.

- Uses Terraform to provision AWS networking, EC2 instances, IAM and security groups.
- Separates the Jenkins server from the application server.
- Builds and runs the application with Docker Compose, with Nginx acting as the public reverse proxy.
- Automates deployment when code changes are detected in GitHub.
- Applies access restrictions to management ports and limits SSH access between servers.

### 4. [Digital Forensics Investigation](https://github.com/praise-oguns/blue-team-digital-forensics-investigation)
